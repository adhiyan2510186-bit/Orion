# Basemap asset provenance

Everything in this directory is generated by `npm run basemap`
(`frontend/scripts/build-basemap.mjs`) and **committed deliberately**, so the repo
clones and runs with no network and no API key. See `docs/adr/0004-offline-basemap.md`
for why the geography is baked in rather than tiled.

Do not hand-edit these files. Change the script and re-run it.

## Files

| File | Source | Derivation |
|---|---|---|
| `land.json` | Natural Earth `ne_110m_land` | Rings simplified at 0.08°, coords rounded to 2 dp, rings under 0.05 deg² dropped |
| `coastline.json` | Natural Earth `ne_110m_coastline` | Simplified at 0.08°, rounded to 2 dp |
| `bathymetry.json` | Natural Earth `ne_10m_bathymetry_{K_200,J_1000,I_2000,H_3000,G_4000,F_5000,E_6000}` | Simplified at 0.25°, rounded to 2 dp, rings under 1.5 deg² dropped. **49 MB raw → 505 KB** |
| `ocean-labels.json` | Natural Earth `ne_110m_geography_marine_polys` | Name + bounding-box centre + scalerank only |
| `earth-bathy.jpg` | NASA Blue Marble Next Generation, `world.topo.bathy.200412.3x5400x2700.jpg` | Downloaded verbatim, 5400×2700 |

Bathymetry is published by Natural Earth **only at 10m scale** — there is no 110m or 50m
edition — which is why it is the one layer that needs aggressive decimation.

## Projection

All assets are **equirectangular (plate carrée)**. The map renders in deck.gl
`OrbitView`, whose world coordinates *are* degrees of longitude and latitude, so
`earth-bathy.jpg` maps onto `bounds: [-180, -90, 180, 90]` with **zero reprojection
error** and the vector coordinates are used as-is. Web-Mercator tiles would need
reprojection and are not usable here.
